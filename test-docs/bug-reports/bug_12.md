# BUG_012 下单商品 ID 未做数字校验
- **模块**：下单
- **严重程度**：中
- **优先级**：P2
- **涉及用例**：ORDER_020
- **测试方法**：等价类划分 + 错误推测法
- **发现日期**：2026-09-19
- **状态**：未修复
---
**复现步骤**
  1. 运行 app.py，用 huang_test_1001 / 123456 登录
  2. Postman 新建 POST 请求，地址 http://127.0.0.1:5000/create_order
  3. Body 选 x-www-form-urlencoded：product_id 填 101abc，quantity 填 1
  4. 点 Send

**预期结果**
提示「商品不存在」，商品 ID 含非数字字符时应被拦截

**实际结果**
提示「下单成功」，MySQL 把 101abc 隐式转成 101，命中在售的 101 号商品并下单

**原因**
create_order() 对商品 ID 没有数字校验，参数化只防注入、不防类型隐式转换；纯字母会转成 0，恰好没有 0 号商品才提示商品不存在
---
**修复建议**
商品 ID 先做 isdigit 校验，非纯数字直接提示「商品不存在」并 return
