# BUG_006 登录接口空参无校验：用户名、密码全空提交返回「密码错误」
- **模块**：登录接口
- **严重程度**：低
- **优先级**：P2
- **涉及用例**：登录健壮性
- **测试方法**：错误推测法 + 等价类
- **发现日期**：2026-09-22
- **状态**：已修复，回归通过
---
**复现步骤**
  1. 运行 app.py
  2. 浏览器打开 http://127.0.0.1:5000/page/login
  3. 用户名、密码全部留空，直接点登录

**预期结果**  
返回 code 1 与用户名不能为空，不进入查库比对

**实际结果**  
返回 code 1，提示密码错误——空请求未被拦下

**原因**  
/login 取参后未判空、直接查库：username 为空字符串时，命中库中 username 为空的历史行（user_id 69），密码比对不过，报密码错误。
---
**修复建议**  
取参后先判空再查库：username（strip 后）为空 → 返回用户名不能为空；password 同法。与 BUG_014/016 同批修复
