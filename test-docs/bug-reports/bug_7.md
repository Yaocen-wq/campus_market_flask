# BUG_007 注册未校验邮箱格式
- **模块**：注册
- **严重程度**：中
- **优先级**：P2
- **涉及用例**：REG_010
- **测试方法**：等价类划分
- **发现日期**：2026-09
- **状态**：未修复
---
**复现步骤**
  1. 运行 app.py
  2. 打开 http://127.0.0.1:5000/page/register
  3. 用户名填 test010，密码填 123456，邮箱填 t10school.edu，手机号填 13800138010
  4. 点注册

**预期结果**
提示邮箱格式错误，注册失败，users 表不新增数据

**实际结果**
提示注册成功，无效邮箱 t10school.edu 被写入 users 表

**原因**
register() 只校验了邮箱是否为空，没有校验格式，无效邮箱直接进库
---
**修复建议**
注册前校验邮箱格式，不符合则提示邮箱格式错误并 return
