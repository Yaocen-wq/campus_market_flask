# BUG_004 下单未校验负数数量
- **模块**：下单
- **严重程度**：高
- **优先级**：P2
- **涉及用例**：ORDER_004
- **测试方法**：等价类划分
- **发现日期**：2026-09-01
- **状态**：已修复，回归通过
---
**复现步骤**
  1. 运行 app.py，用 huang_test_1001 / 123456 登录
  2. 打开 http://127.0.0.1:5000/page/order
  3. 商品 ID 填 101，数量填 -1，点下单

**预期结果**
提示数量不能为负，下单失败

**实际结果（修复前）**
提示下单成功，orders 表多了一条数量为负、金额为负的订单

**原因**
place_order() 没有校验数量，负数直接计算金额并进库
---
**修复建议**
下单前判断数量是否为大于 0 的整数，不符合则提示并 return
