# BUG_008 注册未校验手机号位数
- **模块**：注册
- **严重程度**：中
- **优先级**：P2
- **涉及用例**：REG_011
- **测试方法**：等价类划分 + 边界值分析
- **发现日期**：2026-09
- **状态**：未修复
---
**复现步骤**
  1. 运行 app.py
  2. 打开 http://127.0.0.1:5000/page/register
  3. 用户名填 test011，密码填 123456，邮箱填 t11@school.edu
  4. 手机号填 1380013800（10 位），点注册

**预期结果**
提示手机号格式错误，注册失败

**实际结果**
提示注册成功，10 位手机号被写入 users 表

**原因**
register() 只校验了手机号是否为空，没有校验位数，位数不足也放行
---
**修复建议**
注册前校验手机号必须为 11 位数字，不符合则提示手机号格式错误并 return
