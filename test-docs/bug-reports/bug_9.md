# BUG_009 注册未校验手机号含字母
- **模块**：注册
- **严重程度**：中
- **优先级**：P2
- **涉及用例**：REG_012
- **测试方法**：等价类划分
- **发现日期**：2026-09
- **状态**：未修复
---
**复现步骤**
  1. 运行 app.py
  2. 打开 http://127.0.0.1:5000/page/register
  3. 用户名填 test012，密码填 123456，邮箱填 t12@school.edu
  4. 手机号填 1380013800a，点注册

**预期结果**
提示手机号格式错误，注册失败

**实际结果**
提示注册成功，含字母手机号被写入 users 表

**原因**
register() 没有校验手机号的字符类型，任何字符都能入库
---
**修复建议**
校验手机号只允许数字，不符合则提示手机号格式错误并 return
