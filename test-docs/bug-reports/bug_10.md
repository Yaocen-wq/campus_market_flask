# BUG_010 注册未校验用户名中间空格
- **模块**：注册
- **严重程度**：中
- **优先级**：P2
- **涉及用例**：REG_013
- **测试方法**：等价类划分
- **发现日期**：2026-09
- **状态**：未修复
---
**复现步骤**
  1. 运行 app.py
  2. 打开 http://127.0.0.1:5000/page/register
  3. 用户名填 test 013（中间带空格）
  4. 密码填 123456，邮箱填 t13@school.edu，手机号填 13800138013，点注册

**预期结果**
提示用户名含有非法字符，注册失败

**实际结果**
提示注册成功，用户名 test 013 被写入 users 表

**原因**
register() 只用 strip() 拦了空字符串和全空格，用户名字符校验缺失，中间空格未被识别
---
**修复建议**
校验用户名只允许字母、数字、下划线，含空格或其他特殊字符时提示用户名含有非法字符并 return
