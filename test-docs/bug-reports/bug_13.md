# BUG_013 注册、发布未完整校验纯空格
- **模块**：注册、发布商品
- **严重程度**：中
- **优先级**：P2
- **涉及用例**：REG_016、PUB_013
- **测试方法**：边界值分析
- **发现日期**：2026-09-19
- **状态**：已修复，回归通过
---
**复现步骤**
  1. 运行 app.py，用 huang_test_1001 / 123456 登录
  2. 打开 http://127.0.0.1:5000/page/publish ，商品名连按两个空格，价格填 30，其余字段正常填，点发布
  3. 打开 http://127.0.0.1:5000/page/register ，用户名连按两个空格（试 3、4、5 个现象相同），其余字段正常填，点注册

**预期结果**
发布提示请输入商品名，发布失败；注册提示「用户名不能为空」，注册失败

**实际结果（修复前）**
发布提示发布成功；注册提示注册成功，2 个及以上空格均未被拦截

**原因**
publish_product() 只拦了商品名为空和正好一个空格两种情况，register() 的用户名判断写法相同；2 个及以上空格不在拦截范围内，属校验不完整
---
**修复建议**
改用 strip() 判断，去掉两头空格后为空就拦截，任意数量的纯空格都能拦住
