# BUG_003 发布商品价格为空
- **模块**：发布商品
- **严重程度**：中
- **优先级**：P2
- **涉及用例**：PUB_004
- **测试方法**：等价类划分
- **发现日期**：2026-09-01
- **状态**：已修复，现行版本会提示价格不能为空
---
**复现步骤**
  1. 运行 app.py，用 huang_test_1001 / 123456 登录
  2. 打开 http://127.0.0.1:5000/page/publish
  3. 商品名填 高数教材，描述填 九成新，价格留空，分类填 教材
  4. 点发布

**预期结果**
提示价格不能为空，发布失败

**实际结果（修复前）**
提示发布失败，已回滚 (1366, decimal value...)」，数据库原始报错直接暴露给用户

**原因**
publish_product() 没有校验价格是否为空，靠数据库报错兜底，原始报错被原样打印
---
**修复建议**
发布前先判断价格是否为空，为空则提示价格不能为空并 return；不要把底层报错直接展示给用户
