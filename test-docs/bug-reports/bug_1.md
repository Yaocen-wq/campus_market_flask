# BUG_001 注册缺少空值校验
- **模块**：注册
- **严重程度**：高
- **优先级**：P2
- **涉及用例**：REG_002、REG_003、REG_004
- **测试方法**：等价类划分 + 边界值分析
- **发现日期**：2026-08-29 手工测试发现，2026-09-01 执行用例复现
- **状态**：已修复，回归通过
---
**复现步骤**
  1. 运行 app.py
  2. 打开 http://127.0.0.1:5000/page/register
  3. 用户名填 test002，密码留空，邮箱和手机号正常填，点注册
  4. 邮箱留空、手机号留空时现象相同

**预期结果**
提示密码不能为空，注册失败，users 表不新增数据

**实际结果（修复前）**
提示「注册成功」，空字段被写入 users 表

**原因**
register() 缺少空值校验，空字符串直接进库；数据库也没有非空约束
---
**修复建议**
注册前先判断四个字段是否为空，为空则提示并 return；密码另加长度校验
