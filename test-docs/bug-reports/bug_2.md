# BUG_002 发布商品未校验负价格
- **模块**：发布商品
- **严重程度**：高
- **优先级**：P2
- **涉及用例**：PUB_002
- **测试方法**：等价类划分
- **发现日期**：2026-08-29 手工测试发现，2026-09-01 执行用例复现
- **状态**：已修复，回归通过
---
**复现步骤**
  1. 运行 app.py，用 huang_test_1001 / 123456 登录
  2. 打开 http://127.0.0.1:5000/page/publish
  3. 商品名填 高数教材，描述填 九成新，价格填 -30，分类填 教材
  4. 点发布

**预期结果**
提示价格不能为负，发布失败

**实际结果（修复前）**
提示发布成功，products 表新增价格为 -30 的商品

**原因**
publish_product() 没有校验价格范围，负数直接进库
---
**修复建议**
发布前判断价格是数字且大于 0，不符合则提示并 return
