# BUG_011 下单未拦截购买自己的商品
- **模块**：下单
- **严重程度**：轻微
- **优先级**：低
- **涉及用例**：ORDER_013
- **测试方法**：场景法
- **发现日期**：2026-09
- **状态**：未修复
---
**复现步骤**
  1. 运行 app.py，用 huang_test_1001 / 123456 登录
  2. 打开 http://127.0.0.1:5000/page/publish，发布一个商品
  3. 打开 http://127.0.0.1:5000/page/order，在商品列表里找到刚发布的那个商品，记下它的商品 ID
  4. 商品 ID 填这个值，数量填 1，点下单

**预期结果**
提示不能购买自己的商品，下单失败

**实际结果**
提示下单成功，订单写入 orders 表，买家与卖家是同一个账号

**原因**
create_order() 没有校验买家与卖家是否为同一人，自己买自己直接放行
---
**修复建议**
下单前比对当前 user_id 与查询到的 seller_id，相同则提示不能购买自己的商品并 return
